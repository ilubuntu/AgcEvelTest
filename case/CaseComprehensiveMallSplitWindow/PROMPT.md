# 综合商城分屏购物能力任务

## 窗口状态规格

| 场景 | 主窗口 | 分屏窗口 | 用户结果 |
|---|---|---|---|
| 分屏前 | 全屏商品详情 | 不存在 | 单窗口购物 |
| 分屏建立 | 主区域 | 次区域 | 两侧相同商品 |
| 分屏浏览 | 独立页面历史 | 独立浏览 | 操作不串窗口 |
| 从分屏合并 | 恢复全屏，保留原页面 | 关闭 | 回到主窗口原页面 |
| 从主窗口合并 | 恢复全屏，接管分屏页面 | 关闭 | 继续分屏浏览进度 |
| 系统关闭分屏 | 恢复全屏 | 销毁 | 状态复位，可再次分屏 |

## 核心能力

- 商品详情页点击分屏入口，创建分屏窗口显示相同商品
- 两窗口独立浏览，共享业务数据
- 轻提示/弹层/返回操作在当前窗口
- 从任一侧合并，保留目标窗口的浏览进度
- 分屏后两窗口均显示合并入口
- 合并后可再次发起分屏
