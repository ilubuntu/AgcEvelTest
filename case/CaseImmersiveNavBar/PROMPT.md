# 提示词
请帮我对商品页面做沉浸式适配，要求如下：

1. 这是商品页面的需求，只对商品页面生效，不要影响应用里的其他页面。
2. 我希望商品页面的背景和实际内容（商品大图、详情、价格等）都能铺满整个屏幕，
   让内容真正延伸到屏幕底部边缘（覆盖到底部系统导航条所在的区域），
   而不只是背景颜色延伸过去。
3. 因为内容铺到了底部，会和系统导航条手势区发生重叠，所以需要手动把商品页面
   底部的交互元素（如加入购物车、立即购买按钮）避让开——但只避让底部导航条，
   顶部状态栏不需要处理（商品大图顶部已有自己的布局/不会进入状态栏）。
4. 配置一次就能在全屏、分屏、悬浮窗以及横竖屏切换下都自动生效。
