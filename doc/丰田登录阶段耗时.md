## Bash 工具调用失败说明

本次适配过程中的 14 次失败不是 14 种不同的命令错误，而是同一类 **Bash 工具调用参数截断**。错误信息均为：

```text
JSON Parse error: Unterminated string
```

VS Code 插件为了让 Agent 能在非终端启动的环境中找到 HarmonyOS 工具链，会在每条 Bash 命令前自动注入 `JAVA_HOME`、`DEVECO_HOME`、SDK 路径以及 `hvigor`、`ohpm`、`hdc` 等 `PATH`。同时会清理旧的 Flutter 环境变量，避免当前工程误用其他 Flutter SDK。这个注入目的本身是合理的。

问题在于环境注入实现没有防止重复处理。当同一条命令被再次包装时，环境前缀不断变长，最终在传给 Bash 工具前被截断，导致 JSON 缺少结尾引号，命令尚未真正执行就失败。每次失败后 Agent 需要重新生成、拆分或改用临时脚本执行，因此产生了额外调度和重试耗时。

更准确的结论是：**14 次 Bash 工具参数因重复注入环境而截断，产生约 13 分 45 秒的估算重试开销**。这不是 `ui-multi` Skill、DevEco CLI 或具体 Shell 命令的语法错误，问题属于 VS Code 插件内的 OpenCode 工具链环境注入层。
